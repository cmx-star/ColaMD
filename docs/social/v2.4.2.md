# loomark v2.4.2 Social Copy

## Chinese

loomark 2.4.2 已发布，这一版只动 Windows 的那一行，都是真机实测反馈之后改的。

- **窗口按钮和行里的图标同一个浓度**：系统那三个按钮的颜色要由我们交给系统，之前交错了，它们比行里其他图标都黑，深色主题下又反过来
- **菜单按钮挪到整行最左端**：Windows 上找菜单和选项在左边，右端留给系统的三个按钮；macOS 不变
- **菜单按钮左右间距对称**：之前左边空 14px、右边贴着标签条，现在左右各 6px

免费、开源，文件永远是最新的。

## English

loomark 2.4.2 is out. It only touches the Windows row, and every change came from real-machine feedback.

- **The window buttons now sit at the row icons' own weight**: the OS paints those three, so we hand it the colour. The first attempt handed it the document's ink, which made them darker than everything else in the row (and, in dark themes, the other way round)
- **The menu button moves to the row's left end**, where Windows users look for menus, leaving the right end to the system's three buttons; macOS is unchanged
- **Its spacing is even on both sides**: it used to have 14px on the left and none on the right, and now it has 6px on each side

Free, open source, and your files are always current.
