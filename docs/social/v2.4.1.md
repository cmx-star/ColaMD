# loomark v2.4.1 Social Copy

## Chinese

loomark 2.4.1 已发布，这一版是 2.4.0 之后的收尾：把全屏、Windows 和几处看着不顺眼的地方一起修了。

- **全屏时标签贴到窗口左边**：以前进全屏，标签左边会空出一块，那是留给 macOS 红绿灯的位置，而全屏下红绿灯并不在
- **Windows 顶栏只剩一行**：以前系统标题栏、菜单栏、顶行三条叠在一起。现在窗口按钮由系统画进这一行，菜单移到行尾的第四个图标，按 Alt 仍然能唤出系统菜单栏
- **Windows 上标签文字不再缺一截**：中文在 Windows 的字体下略高，标签名字框刚好只够一行，底部会被裁掉
- **新建标签就能直接打字**：光标默认在正文里，不用先点一下
- **菜单里的 Window 变成「窗口」**：中文界面下不再夹一个英文词
- **文件列表图标换了方向**：面板在右边，图标上的竖线也画在右边
- **键盘焦点框跟主题走**：不再用系统强调色
- **更新更可靠**：升级了底层运行时，修好了 macOS 上「更新下载完、应用退出后没再回来」的问题

免费、开源，文件永远是最新的。

## English

loomark 2.4.1 is out: the loose ends from 2.4.0, in one pass.

- **Full screen stops reserving room for traffic lights** that are not there
- **Windows gets one row instead of three stacked bars**: the window controls are painted by the system inside our own row, the menu sits there as the row's fourth icon, and Alt still brings up the system menu bar
- **Tab labels on Windows are no longer clipped** at the bottom: Chinese glyphs are taller with Windows fonts, and the label's box only just fit one line
- **A new tab is ready to type in**, caret included, with no click first
- **The Window menu speaks the interface language** instead of leaving one English word in a Chinese menu
- **The file-list icon points the right way**: the panel lives on the right now, so the icon's divider does too
- **The keyboard focus ring follows the theme** instead of the system accent colour
- **Updates are more reliable**: a newer runtime fixes the macOS case where the update downloaded, the app quit, and the app never came back

Free, open source, and your files are always current.
