# loomark v2.6.0 Social Copy

## Chinese

loomark 2.6.0 已发布。这一版把「导出的东西」和「没来得及存的东西」都补上了。

- **导出的 Word 里带上 Mermaid 图**：以前 Word 里只有一段图的源码。Word 导出走的是 Markdown 那条路，它看不懂图，现在每个图都会先画成图片再放进文档。用的是浅色配色，因为 Word 是白纸，屏幕上那张可能是深色的；正在改源码的图块、甚至整个源码模式下导出，图照样在里面。谢谢 flywhale 提的这个需求
- **正文宽度三档**：视图 → 正文宽度，窄 640 / 标准 780 / 宽 1080。宽屏上不再只是中间窄窄一条，切到源码模式文字位置和正文对齐，导出的 HTML 和 PDF 也跟着走
- **丢弃未保存内容之前，先留一份副本**：外部改过文件、你选择「加载磁盘版本」的时候，这是全应用唯一一个会把你的输入就地抹掉的动怍。现在被丢弃的那份会先写到 `~/.loomark/recovered`，对话框的按钮上就写着这件事，标题栏随后告诉你去哪找，点一下直接在文件管理器里亮出来。副本写不成功就不丢弃
- **标签关闭按钮好点了**：可见的叉号仍然 16×16，可点的范围扩到了 24×24

后三条都来自社区提的 issue，谢谢 moyu12-ae 和 CyrilDavid1031。

免费、开源，文件永远是最新的。

## English

loomark 2.6.0 is out. This one is about what leaves the app and what could have been lost.

- **Mermaid diagrams travel into the Word export**: the .docx used to carry the diagram's source text and nothing else, because that export reads Markdown and cannot see a drawing. Every diagram is now drawn into the document as a picture, in the light palette, since Word is a white page and the one on screen may belong to a dark theme. A block whose source is open for editing, or a whole document exported from source mode, still gets its diagram. Thanks to flywhale for asking
- **Three reading widths**: View → Text Width, narrow 640 / standard 780 / wide 1080. A wide display is no longer a narrow strip down the middle, source mode keeps the text in the same place, and the HTML and PDF exports follow
- **A copy is kept before unsaved work is discarded**: when an external program has changed the file and you choose to load the disk version, that was the one action in the app that threw your input away with no trace. The dropped version now goes to `~/.loomark/recovered` first, the dialog button says so before it happens, the title bar says where it went and opens the folder when clicked. If the copy cannot be written, nothing is discarded
- **The tab close button is easier to hit**: the visible cross stays 16×16, the target is 24×24

The last three came from issues opened by people using the app. Thank you moyu12-ae and CyrilDavid1031.

Free, open source, and your files are always current.
