# loomark v2.0.7 Social Copy

## Chinese

loomark 2.0.7 已发布，最直观的变化是安装包小了一大半。

- **macOS 按芯片发布**：以前是一个「两套架构合一」的通用包（216MB），现在按芯片分别下载，首次下载约 **82MB（Apple 芯片）/ 85MB（Intel 芯片）**。包里不再有你用不到的那套运行时
- **Windows 免安装版**：新增 zip 版，解压即用，不写注册表，卸载就是删文件夹。代价是不注册 `.md` 关联、不支持应用内更新
- **文件面板右键菜单**：在文件面板里右键，可以复制路径、用默认应用打开、在 Finder 或资源管理器中显示
- **标题永远居中**：以前「已编辑」一出现，文件名会被挤偏，现在它稳稳在中间
- **顺手瘦身**：包内被复制了第二遍的依赖库清掉了

免费、开源、本地优先，支持 macOS、Windows 与 Linux。应用内会自动提示更新，也可以直接下载：

Apple 芯片（M 系列）：https://github.com/marswaveai/loomark/releases/download/v2.0.7/loomark-2.0.7-arm64.dmg
Intel 芯片（旧款 Mac）：https://github.com/marswaveai/loomark/releases/download/v2.0.7/loomark-2.0.7-x64.dmg
Windows 安装版 / 免安装 zip：https://github.com/marswaveai/loomark/releases/tag/v2.0.7

## English

loomark 2.0.7 is out, and the most visible change is a much smaller download.

- macOS builds are now per architecture: the single universal download (216 MB) is gone, replaced by about **82 MB for Apple silicon and 85 MB for Intel**. You no longer download a runtime for the other chip
- A Windows zip build you can run without installing. Nothing in the registry, delete the folder to remove it. It gives up the `.md` association and in-app updates
- Right-click in the file panel to copy a path, open a file in the default app, or reveal it in Finder or File Explorer
- The document title stays centred now. Before, the "Edited" hint pushed it off centre
- Housekeeping: the duplicated dependency copy inside the app is gone

Free, open source, local first, available on macOS, Windows and Linux. The app updates itself, or download directly:

Apple silicon: https://github.com/marswaveai/loomark/releases/download/v2.0.7/loomark-2.0.7-arm64.dmg
Intel Macs: https://github.com/marswaveai/loomark/releases/download/v2.0.7/loomark-2.0.7-x64.dmg
Windows installer or zip: https://github.com/marswaveai/loomark/releases/tag/v2.0.7
