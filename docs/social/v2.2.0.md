# loomark v2.2.0 Social Copy

## Chinese

loomark 2.2.0 已发布，这一版把顶栏收成了一行。

标签栏常驻，一个文档也是一个标签，和标题栏合成一行，窗口顶部不再随着开第二个文档而变一副样子。原来居中的文件名由活动标签承担，要看路径就右键标签。

- **再打开文件，落成标签页**：双开图标不会再多开一个实例，没开过的文件在当前窗口新开一个标签
- **窗口记住大小和缩放**：下次启动按上次的来，外接屏拔了也不会开到看不见的地方
- **PDF 导出像纸了**：上下 20mm、左右 18mm 的页边距，页面底色跟随主题
- **编辑菜单多了「格式」**：加粗、斜体、行内代码、删除线、链接、列表都有快捷键
- **深色主题全面校色**：悬停、选中、面板托盘，该看得见的都看得见

免费、开源、本地优先，支持 macOS、Windows 与 Linux。应用内会自动提示更新，也可以直接下载：

## English

loomark 2.2.0 is out. The top of the window is now one row, always.

The tab strip is always there, a single document is a tab, and it shares the row with the title bar. The window top no longer changes shape when a second document shows up. The centred filename is gone; the active tab carries the name, and a right-click on the tab shows the path.

- **Opened files land as tabs**: launching the app twice no longer starts a second instance; new files open as tabs in the window you are in
- **The window remembers its size and zoom**: external display unplugged, it still opens somewhere visible
- **PDF export looks like paper**: 20 mm top and bottom, 18 mm side margins, page background follows the theme
- **A Format submenu**: bold, italic, inline code, strikethrough, links and lists, all with shortcuts
- **Dark themes are recalibrated**: hover, selection and the panel tray are finally visible without being loud

Free, open source, local first, on macOS, Windows and Linux. The app offers updates on its own, or download directly:
