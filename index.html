ColaMD
The beginning

A free Markdown editor should be on every computer.

ColaMD began with a simple wish: everyone should have a free, beautiful, capable Markdown editor on their computer.

Open source and free forever. Staying in sync with the file is one of our differences, but the first promise is simpler: Markdown should be available to everyone.

Everything you need in a Markdown editor.

01

True WYSIWYG

Type Markdown and see rich text directly. No split-pane preview, nothing to learn.

02

Always in Sync

When the file changes on disk, whether by an AI agent, a script or another editor, the editor updates right away. No reopening, no manual refresh.

03

Export

Turn a document into Word, PDF, a self-contained HTML file or a shareable image, with your theme colors kept.

04

Tabs

Keep several documents open in one window (⌘T opens a new tab). Each tab holds its own content, undo history and scroll position, and switching never mixes them.

05

Diagrams

Render Mermaid flowcharts and sequence diagrams right inside the document, with colors that follow your theme.

06

Same-Directory Files

Browse and switch between the Markdown files in the current folder, and drag the panel to the width you like. Files created by an agent appear automatically.

07

Outline & Find

Never lose your place in a long document: jump between headings, see the current section highlighted, and find or replace inside the document.

08

Rich Text Copy

Copy content with formatting preserved into WeChat, email and other rich-text editors.

09

Cross-Platform

Available for macOS, Windows and Linux, with English and Chinese interfaces. Free and open source.
